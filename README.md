# Cawl Online Payments

PrestaShop 8 plugin for the Cawl payment solutions.

## PrestaShop Compatibility

Module is compatible with PrestaShop versions: 8.0.1 - 8.x.x
We do not guarantee support for earlier versions and other modules included in our migration

## Compatibility with other payment solutions

Please note that at this time, the Cawl payment solutions module is not compatible with the [Worldline payment solutions](https://github.com/wl-online-payments-direct/plugin-prestashop-8) module.
